# Ahara

Premium mobile-first Next.js frontend MVP for a modern fast-casual Indian restaurant.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run

1. Install dependencies with your package manager of choice.
2. Start the dev server.

```bash
npm install
npm run dev
```

If you prefer `pnpm` or `yarn`, the project structure is standard and should work the same way.
